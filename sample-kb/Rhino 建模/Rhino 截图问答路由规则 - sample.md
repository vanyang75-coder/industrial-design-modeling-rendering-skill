# Rhino Screenshot Routing Rules - Sample

Use this sample file to test screenshot-first retrieval.

## General Flow

1. Identify the screenshot stage: reference setup, blockout, main surface, Boolean/detail, fillet/chamfer, or render prep.
2. Identify product family: handheld product, airflow product, revolved container, consumer electronics, personal care, medical/protective shell, or transport shell.
3. Give only the next 1-3 actions unless the user asks for a full workflow.
4. Add one failure check that matches the visible stage.

## Stage Keywords

- Reference setup: 参考图, 比例, 中心线, 图层.
- Blockout: 大体块, 轮廓, 基准面, 对称.
- Main surface: 曲面, 放样, 双轨, 扫掠, 连续.
- Boolean/detail: 布尔, 孔, 槽, 格栅, 分件.
- Fillet/chamfer: 倒角, 圆角, 半径, 边缘.
- Render prep: 材质分件, 法线, 封闭, 命名.
