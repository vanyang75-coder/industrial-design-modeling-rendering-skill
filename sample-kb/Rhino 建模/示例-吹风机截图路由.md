# Sample - Hair Dryer Rhino Screenshot Route

## Product Family

Hair dryer / airflow handheld product.

## Visual Cues

- Long handle connected to a larger airflow body.
- Nozzle or outlet opening.
- Intake grille, vent slots, or perforated detail.
- Trigger/button area near the handle.

## Modeling Route

1. Lock the side silhouette and handle angle before adding grille details.
2. Build the main body and handle as clean primary surfaces or solids.
3. Plan parting lines and vent areas as separate detail zones.
4. Run Boolean cuts before small fillets.
5. Add large fillets first, then small edge highlights.

## Failure Checks

- If Boolean cuts fail, check cutter penetration and closed solid status.
- If fillets fail near vents, reduce radius and remove sliver surfaces before retrying.
- If the shell looks wavy, simplify guide curves before adding panel seams.
